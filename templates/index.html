HOW TO DEMO
1
HR VIEW
Set up Sarah's return
Go to HR → Change Digest. Publish a "What Changed" update. Or go to Add Returner to create a new employee.
2
EMPLOYEE VIEW
Sarah checks in for the first time
Set demo date to Day 7. Open Employee → see the What Changed card. Go to Weekly Check-in and submit with low scores (2–3 /5).
3
HR VIEW
HR sees the confidence alert
Return to HR → Overview. The Attention Needed count increases and the confidence trend chart updates in real time.
4
MANAGER VIEW
Manager responds and sends feedback
Open Manager → low confidence bars visible across all 5 dimensions. Dismiss a Bias Nudge, send a message to Sarah, add a task to her checklist.
5
EMPLOYEE VIEW
Sarah sees the manager's message
Return to Employee → Resources & Buddy. The "From Your Manager" section shows Tom's message live. The new task appears in her checklist. She can write a diary entry about how she's feeling.
