DEMO GUIDE — THREE PERSPECTIVES
EMPLOYEE
Sarah's Return Journey
1
Day 1 — Read What Changed
Open Employee view. Dashboard shows updates HR published about the team while you were away.
2
Week 1 — Complete your checklist
Tick off onboarding tasks: meet your buddy, confirm IT access, join team meetings.
3
Set Day 7 → submit a check-in
Weekly Check-in tab. Rate all 5 dimensions (try 2–3/5 to trigger an alert). Add a note.
4
Read manager's message & write diary
Resources tab shows the manager's message. Diary tab — pick a mood and write privately.
5
Set Day 30/60/90 — track progress
Watch the confidence score grow as you submit more check-ins. Tasks shift across phases.
Day 1–30
Settle in, tick off checklist, weekly check-ins
Day 31–60
Build momentum, take on first project
Day 61–90
Full reintegration, 90-day review
HR
HR Coordinator Journey
1
Add a returner
HR → Add Returner. Fill in name, role, return date, assign manager & buddy. Employee link is generated instantly.
2
Publish What Changed digest
HR → Change Digest. Add updates about process, tools, team or policy changes since the employee left.
3
Monitor the Overview dashboard
Watch for the red "Needs Attention" dot. Any check-in average below 3/5 triggers an alert with the employee's name.
4
Send guidance to the manager
Overview → Send Manager Guidance. Select the employee and write an action item the manager should act on this week.
5
Track confidence over time
HR → Confidence Tracker. Select an employee to see all 5 dimension scores across every check-in.
Day 1–30
Monitor first scores, send manager nudges
Day 31–60
Review 30-day trend, update return plan
Day 61–90
Prepare close-out report
MANAGER
Manager Journey
1
Read the Bias Nudge
Manager → Bias Nudge tab. Review the active alert about unconscious exclusion patterns. Dismiss once addressed.
2
Check the confidence overview
Overview dashboard shows all 5 check-in dimensions from Sarah's latest submission. Low bars = action needed.
3
Complete HR action items
Overview → This Week's Actions. HR sends specific tasks (e.g. "Schedule a 1:1"). Tick them off as done.
4
Send Sarah a message
Overview → Send a Message. Write encouragement — it appears live in Sarah's Resources tab.
5
Add a task & track the timeline
Timeline tab → Add a Task to Sarah's checklist. See the 30/60/90-day milestone timeline and your phase responsibilities.
Day 1–30
Weekly 1:1s, invite to all meetings
Day 31–60
30-day review, offer first project
Day 61–90
60-day review, high-visibility work
